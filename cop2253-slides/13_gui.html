What Is a GUI?

Programs Can Talk to Users in Different Ways

So far, many of our programs have used text input and text output.

  • A console program prints text to the screen.

  • The user types input using the keyboard.

  • The program usually runs from top to bottom.

  • This is simple and good for learning basic programming.

Enter miles: 120

Console programs use text interaction.

A GUI Uses Visual Objects

A graphical user interface lets the user interact with visual objects.

  • GUI means graphical user interface.

  • The user sees windows, labels, text fields, buttons, menus, and tables.

  • The user can click, type, select, and scroll.

  • The program responds to the user's actions.

A GUI program uses visual components.

GUI Programs Are Event Driven

In a GUI program, the program often waits for the user to do something.

  • The user types in a field.

  • The user clicks a button.

  • The user selects an item.

  • The program runs the matching code for that action.

For example, clicking a calculate button can tell the program to read input, do math, and show a result.

Swing GUI Building Blocks

A Swing Window Holds Components

A Swing GUI program is built by placing visual components inside a window.

  • A JFrame is the main window.

  • A JLabel shows text to the user.

  • A JTextField lets the user type input.

  • A JButton lets the user start an action.

  • Another text field can show the program result.

Example: Build a Simple Swing Window

This code creates three Swing components and adds them to the window.

JLabel wageLabel = new JLabel("Hourly wage:");
JTextField wageField = new JTextField(10);
JButton calculateButton = new JButton("Calculate");

add(wageLabel);
add(wageField);
add(calculateButton);

  • Each component is created as an object.

  • The add() method places the component in the window.

  • Layout code controls the final position of each component.

Events

A Button Click Is an Event

An event is something that happens while the program is running.

  • The user clicks a button.

  • The button tells the program that something happened.

  • The program runs the code connected to that button.

  • The output on the screen may change.

User clicks Calculate
Program reads the miles
Program calculates the hours
Program displays the result

Event Handler Means Response Code

An event handler is code that runs when an event happens.

button.addActionListener(event -> {
    double miles = Double.parseDouble(milesField.getText());
    double hours = miles / 60.0;

    resultField.setText(String.format("%.2f", hours));
});

  • The button has a listener.

  • The listener waits for a click.

  • When the click happens, the calculation runs.

GUI Input Still Needs Checking

Users may type values the program cannot use.

  • The field may be empty.

  • The user may type letters instead of a number.

  • The user may type a number that does not make sense.

  • The program should give a clear message instead of crashing.

if (miles <= 0) {
    JOptionPane.showMessageDialog(this,
            "Enter a positive number of miles.");
}

JavaFX

What Is JavaFX?

JavaFX is another Java library for building graphical programs.

  • It lets Java programs create windows.

  • It provides GUI components such as buttons, labels, text fields, and menus.

  • It supports drawing, images, colors, and simple animation.

  • It uses different class names from Swing.

JavaFX helps us build the visual part of the program.

JavaFX Programs Use a Stage and a Scene

JavaFX uses a few new words to describe a GUI program.

JavaFX TermSimple Meaning
StageThe main window.
SceneThe content inside the window.
NodeA visual object, such as a button or label.
Layout paneAn object that arranges nodes.
Event handlerCode that responds to a user action.

The main idea is simple: the stage holds the scene, and the scene holds the visual objects.

JavaFX Program Structure

A JavaFX program has a special starting method named start().

public class HelloFx extends Application {
    @Override
    public void start(Stage stage) {
        Button button = new Button("Click me");

        Scene scene = new Scene(button, 300, 150);
        stage.setScene(scene);
        stage.setTitle("Hello JavaFX");
        stage.show();
    }
}

  • The stage is the window.

  • The scene is placed inside the stage.

  • The button is a visual object inside the scene.

Drawing Simple Graphics

A Canvas Is a Drawing Area

JavaFX can also draw simple shapes. A Canvas gives the program a place to draw.

  • A canvas is like a blank piece of paper inside the window.

  • The program can draw lines, rectangles, circles, and text.

  • Drawing uses x-y coordinates.

  • The coordinate system tells the program where to place each shape.

x increases right
y increases down
(0, 0)
point
Each rectangle starts at a coordinate.

Canvas Uses Coordinates

Coordinates tell the program where something should appear.

  • The point (0, 0) is the top-left corner.

  • The x value increases as you move right.

  • The y value increases as you move down.

  • A rectangle needs an x value, a y value, a width, and a height.

gc.fillRect(10, 75, 150, 50);

  • 10 is the x position.

  • 75 is the y position.

  • 150 is the width.

  • 50 is the height.

GraphicsContext Draws on a Canvas

A GraphicsContext is the object that draws shapes on a JavaFX Canvas.

  • First, create a canvas.

  • Then, get the graphics context from the canvas.

  • Finally, call drawing methods such as fillRect().

Canvas canvas = new Canvas(400, 200);
GraphicsContext gc = canvas.getGraphicsContext2D();

gc.setFill(Color.CORNFLOWERBLUE);
gc.fillRect(10, 75, 150, 50);

Summary

Key Takeaways

GUI programs use visual objects so users can interact with a program more naturally.

  • A GUI is a graphical user interface.

  • Java has more than one GUI library, including Swing and JavaFX.

  • Swing uses classes such as JFrame, JLabel, JTextField, and JButton.

  • JavaFX uses classes such as Application, Stage, Scene, and Canvas.

  • An event is something the user does, such as clicking a button.

  • An event handler is the code that responds to the event.

  • Drawing uses coordinates where x increases right and y increases down.
