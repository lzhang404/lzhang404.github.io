Project 2: Course Gradebook Analyzer

Overview

In this project, you will write a Java program that analyzes a small course gradebook.

Each student has:

  • a name
  • a lab score
  • an exam score
  • a calculated final score
  • a letter grade

The project is designed to practice:

  • loops
  • arrays
  • methods
  • formatted output

The topic is one unified gradebook problem. Every array stores information about the same students.

File and class name

Submit one Java file:

CourseGradebookAnalyzer.java

Your public class must be named:

public class CourseGradebookAnalyzer

Your program must contain a main() method.

Program idea

Your program reads several students.

For each student, the input gives:

studentName labScore examScore

The program calculates each student's final score using this formula:

final score = lab score * 0.40 + exam score * 0.60

Then the program prints:

  • each student's final score and letter grade
  • the class average
  • the student with the highest final score
  • the number of passing students
  • the number of students below the class average

Program input

The first input value is the number of students.

Then each student has one name, one lab score, and one exam score.

numberOfStudents
name1 labScore1 examScore1
name2 labScore2 examScore2
name3 labScore3 examScore3
...

The input may also appear on one line. Since Scanner reads tokens, both formats should work.

Input value descriptions

numberOfStudents: The number of students in the gradebook. This value will be at least 1

name: The student's name. The name will be one token with no spaces.

labScore: The student's lab score. This value will be an integer from 0 through 100.

examScore: The student's exam score. This value will be an integer from 0 through 100.

Required arrays

Your program must use these arrays:

String[] names
int[] labScores
int[] examScores
double[] finalScores

These are parallel arrays.

That means the same index refers to the same student in every array.

Example:

names[2]       -> the third student's name
labScores[2]   -> the third student's lab score
examScores[2]  -> the third student's exam score
finalScores[2] -> the third student's final score

Letter grade rules

Use the final score to assign a letter grade.

A: score >= 90
B: score >= 80 and score < 90
C: score >= 70 and score < 80
D: score >= 60 and score < 70
F: score < 60

A student is passing if the final score is at least 60.00.

Required methods

Your program must include all of the following methods with exactly these method headers.

public static double calculateFinalScore(int labScore, int examScore)

This method calculates and returns one student's final score with this formula: final = labScore * 0.40 + examScore * 0.60

This method should not read input.

This method should not print output.

public static void fillFinalScores(int[] labScores, int[] examScores, double[] finalScores)

This method fills the finalScores array.

Use a loop.

For each index, calculate the final score from the matching lab score and exam score.

Example idea:

finalScores[i] stores the final score for student i

This method should call calculateFinalScore().

This method should not read input.

This method should not print output.

public static double average(double[] values)

This method returns the average of all values in the array.

Formula:

average = sum of values / number of values

Use a loop.

This method should not print output.

public static int indexOfHighest(double[] values)

This method returns the index of the largest value in the array.

If more than one value is tied for highest, return the first highest index.

Example:

values = {87.0, 97.0, 97.0, 75.0}

The method returns:

1

The first 97.0 is at index 1.

public static int countPassing(double[] values)

This method returns how many final scores are at least 60.00.

Use a loop.

public static int countBelowAverage(double[] values)

This method returns how many values are strictly less than the average of the whole array.

This method may call average(values).

Use a loop.

public static char letterGrade(double score)

This method returns the letter grade for one final score.

Return one of these characters:

'A'
'B'
'C'
'D'
'F'

Use branches.

Suggested program structure

Your main() method should:

create Scanner
read numberOfStudents
create names array
create labScores array
create examScores array
create finalScores array

use a loop to read each student's name, lab score, and exam score
call fillFinalScores(labScores, examScores, finalScores)

use a loop to print each student's result
call average(finalScores)
call indexOfHighest(finalScores)
call countPassing(finalScores)
call countBelowAverage(finalScores)
print the summary results

Output format

Your program must print the report in this order:

Student Report
studentName1: finalScore letterGrade
studentName2: finalScore letterGrade
...
Class average: averageValue
Highest student: studentName finalScore
Passing students: count
Below average: count

All final scores and averages must show exactly two digits after the decimal point.

Use System.out.printf() for values that need two decimal places.

Do not print prompts.

Do not print extra blank lines.

Do not print other not required message.

Restrictions

Do not use ArrayList.

Do not use file input.

Do not use sorting methods.

Do not use advanced library methods to replace the required logic.

Do not print inside the required methods.

Do not hard-code the sample answers.

Your program must work for different valid inputs.

Common mistakes to avoid

Do not calculate the average score with integer division.

Do not mix the array indexes

Do not return the highest score from indexOfHighest().

  • That method should return the index of the highest score.

  • The index lets you print both the student's name and final score.
