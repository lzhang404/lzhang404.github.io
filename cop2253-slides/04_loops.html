Loop Concepts

Why Loops?

A loop repeats a group of statements while a condition is true.

Without a loopWith a loop
Copy the same print statement many timesWrite the print statement once
Hard to change laterChange one loop body
Works only for a fixed small numberCan repeat 5 times, 500 times, or until input says stop

  • Each trip through the loop body is called an iteration.

  • A loop must eventually make its condition become false.

The Four Questions for Any Loop

Every loop should answer the same four questions.

QuestionExample answer
Where does the loop start?count = 1
When does the loop continue?count <= 5
What happens each iteration?print the current count
How does the loop move forward?count++

  • If one of these four pieces is missing, the loop will probably be wrong.

While Loops

while Loop Pattern

A while loop checks the condition before each iteration.

int count = 1;

while (count <= 5) {
    System.out.println("Count: " + count);
    count++;
}

  • If the condition is false at the start, the body runs zero times.

  • A while loop is useful when we do not know the number of iterations ahead of time.

Infinite Loops

An infinite loop never reaches a false condition.

int count = 1;

while (count <= 5) {
    System.out.println("Count: " + count);
    // missing count++
}

  • This loop keeps printing Count: 1.

  • When a loop does not stop, check the update statement first.

  • example: MissingUpdateLoopWarning.java

Sentinel-Controlled Loops

A sentinel value is a special input value that means “stop.”

Input listSentinelValues processed
10 1 6 3 0010, 1, 6, 3
9 23 35 -1negative number9, 23, 35

  • The sentinel tells the loop to stop, but the sentinel itself is not part of the calculation.

  • Sentinel loops are common when the amount of input is not known ahead of time.

Sentinel Average

This program averages positive integers and stops when the user enters 0.

import java.util.Scanner;

public class SentinelAverage {
    public static void main(String[] args) {
        Scanner scnr = new Scanner(System.in);
        int currValue = scnr.nextInt();
        int valuesSum = 0;
        int numValues = 0;

        while (currValue > 0) {
            valuesSum = valuesSum + currValue;
            numValues = numValues + 1;
            currValue = scnr.nextInt();
        }

        System.out.println("Average: " + (valuesSum / numValues));
    }
}

  • Sample input: 10 1 6 3 0

  • live coding: SentinelAverage.java

do-while Loop

A do-while loop checks the condition after the body.

int choice;

do {
    System.out.println("1. Continue");
    System.out.println("0. Quit");
    choice = scnr.nextInt();
} while (choice != 0);

  • The body always runs at least once.

  • This pattern is useful for menus and repeated prompts.

Menu Loop: Complete Program

This program keeps showing a menu until the user enters 0.

import java.util.Scanner;

public class MenuLoop {
    public static void main(String[] args) {
        Scanner scnr = new Scanner(System.in);
        int choice;

        do {
            System.out.println("1. Print greeting");
            System.out.println("0. Quit");
            System.out.print("Choice: ");
            choice = scnr.nextInt();

            if (choice == 1) {
                System.out.println("Hello!");
            }
        } while (choice != 0);

        System.out.println("Goodbye");
    }
}

  • Sample input: 1 1 0

  • example: MenuLoop.java

For Loops

for Loop Pattern

A for loop places the counter setup, condition, and update in one line.

for (int count = 1; count <= 5; count++) {
    System.out.println("Count: " + count);
}
PartPurpose
int count = 1start the counter
count <= 5decide whether to keep looping
count++move to the next value

For Loop: Execution Order

The parts of a for loop do not run left-to-right every time.

StepWhat Java doesWhen it happens
1initialize counteronce, before the first condition check
2check conditionbefore every iteration
3run loop bodywhen condition is true
4update counterafter each loop body
5check condition againrepeat until false

Increment and Decrement Operators

The operators ++ and -- change a variable by one.

StatementEquivalent ideaCommon use
count++count = count + 1move a loop counter forward
++countcount = count + 1also increments by one
count--count = count - 1count down
--countcount = count - 1also decrements by one

  • In a loop update section, count++ and ++count are usually equivalent.

  • Inside a larger expression, pre-increment and post-increment can produce different results.

Pre and Post Increment: Complete Program

This example shows why pre-increment and post-increment can differ inside a print statement.

public class IncrementOperators {
    public static void main(String[] args) {
        int num = 5;

        System.out.println("Start: " + num);
        System.out.println("With ++num: " + ++num);
        System.out.println("After ++num: " + num);
        System.out.println("With num++: " + num++);
        System.out.println("After num++: " + num);
    }
}

  • ++num increments before the value is used.

  • num++ uses the value first, then increments.

  • example: IncrementOperators.java

Counting Letters in a String

This program counts only alphabetic characters in a word.

import java.util.Scanner;

public class CountLetters {
    public static void main(String[] args) {
        Scanner scnr = new Scanner(System.in);
        String inputWord = scnr.next();
        int numLetters = 0;

        for (int i = 0; i < inputWord.length(); i++) {
            if (Character.isLetter(inputWord.charAt(i))) {
                numLetters++;
            }
        }

        System.out.println("Number of letters: " + numLetters);
    }
}

Build a New String in a Loop

Sometimes the loop reads one character at a time and builds a cleaned result.

public class RemoveNonAlpha {
    public static void main(String[] args) {
        String text = "Java 101!";
        String lettersOnly = "";

        for (int i = 0; i < text.length(); i++) {
            char current = text.charAt(i);
            if (Character.isLetter(current)) {
                lettersOnly = lettersOnly + current;
            }
        }

        System.out.println(lettersOnly);
    }
}

  • The result grows only when the current character is a letter.

  • example: RemoveNonAlpha.java

Replacing Until Done

A while loop is useful when the program should continue until no matching text remains.

public class SingleSpaces {
    public static void main(String[] args) {
        String userText = "Java    is   fun";

        while (userText.indexOf("  ") != -1) {
            userText = userText.replace("  ", " ");
        }

        System.out.println(userText);
    }
}

  • The loop stops when there are no double spaces left.

  • example: SingleSpaces.java

Nested Loops

Nested Loop Idea

A nested loop is a loop inside another loop.

LoopRoleExample
Outer loopControls the larger repetitionrows in a table
Inner loopRuns completely for each outer iterationcolumns in one row

  • If the outer loop runs 3 times and the inner loop runs 4 times each time, the inner body runs 12 times.

Nested Loop: Multiplication Table

This program prints products for rows 1 through 3 and columns 1 through 4.

public class NestedLoopTable {
    public static void main(String[] args) {
        for (int row = 1; row <= 3; row++) {
            for (int col = 1; col <= 4; col++) {
                System.out.print((row * col) + "	");
            }
            System.out.println();
        }
    }
}

  • The inner loop finishes one whole row before the outer loop moves to the next row.

Histogram with an Inner Loop

This example uses a loop to print one line of stars for each input value.

import java.util.Scanner;

public class Histogram {
    public static void main(String[] args) {
        Scanner scnr = new Scanner(System.in);
        int numAsterisks = scnr.nextInt();

        while (numAsterisks >= 0) {
            for (int i = 0; i < numAsterisks; i++) {
                System.out.print("*");
            }
            System.out.println();
            numAsterisks = scnr.nextInt();
        }

        System.out.println("Goodbye");
    }
}

Break, Continue, and Debugging

break Statement

A break statement exits the nearest loop immediately.

for (int count = 1; count <= 10; count++) {
    if (count == 7) {
        break;
    }
    System.out.print(count + " ");
}
System.out.println();

  • This prints 1 2 3 4 5 6.

  • The loop stops before printing 7.

continue Statement

A continue statement skips the rest of the current iteration.

for (int count = 1; count <= 10; count++) {
    if (count == 5) {
        continue;
    }
    System.out.print(count + " ");
}
System.out.println();

  • This prints every number from 1 to 10 except 5.

  • The loop does not stop. It only skips one iteration.

Break and Continue: Complete Program

This program shows continue and break in the same loop.

public class BreakContinue {
    public static void main(String[] args) {
        for (int count = 1; count <= 10; count++) {
            if (count == 5) {
                continue;
            }
            if (count == 8) {
                break;
            }
            System.out.print(count + " ");
        }
        System.out.println();
    }
}

  • Predict which numbers appear before running the program.

  • example: BreakContinue.java

Develop Loops Incrementally

Loop programs are easier when built in small steps.

  1. First, read one input value and print it back.

  2. Then, write the loop condition and make sure the loop stops.

  3. Next, add the calculation inside the loop.

  4. Then, add formatting and final output.

  5. Finally, test boundary cases and unusual input.

Do not write a long loop and debug everything at once.

Domain Name Validation

This example checks a domain name one character at a time.

  • Allowed: letters, digits, periods, and hyphens.

  • Any other character makes the domain invalid.

public class DomainNameValidation {
    public static void main(String[] args) {
        String domain = "uwf.edu";
        boolean isValid = true;

        for (int i = 0; i < domain.length(); i++) {
            char ch = domain.charAt(i);
            boolean allowed =
                Character.isLetterOrDigit(ch) ||
                ch == '.' ||
                ch == '-';
            if (!allowed) {
                isValid = false;
            }
        }

        System.out.println(domain + " valid? " + isValid);
    }
}

  • example: DomainNameValidation.java

Summary

Key Takeaways

  • A loop repeats while its condition is true.

  • Every loop needs a start, condition, body, and update.

  • Use while for unknown repetition and sentinel-controlled input.

  • Use for for counter-controlled repetition.

  • Use String.length() and charAt() to process text in a loop.

  • Nested loops are useful for tables, grids, combinations, and repeated patterns.

  • break exits a loop; continue skips to the next iteration.

  • Most loop bugs are off-by-one errors, missing updates, or incorrect stop conditions.

Before Next Class

  • Practice tracing loops before running them.

  • For each loop, write down the first value, last value, and stopping condition.

  • Test loops with small input first.

  • When processing input, check whether the sentinel is accidentally included.

  • When processing strings, remember the last valid index is length() - 1.
