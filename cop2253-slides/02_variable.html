Variables and Memory

What Is a Variable?

A variable is a named memory location used to store data while a program runs.

  • The variable name lets the programmer refer to the value later

  • The data type tells Java what kind of value can be stored there

  • The assignment operator = stores a value into the variable

  • A variable's value can change as the program executes

StatementMeaning
int userAge;Declare an integer variable named userAge
userAge = 19;Store the value 19 in that variable
userAge = userAge + 1;Read the old value, add 1, store the new value

Declaration, Initialization, Assignment

These three words are easy to mix up. They describe different moments in a variable's life.

TermExampleMeaning
Declarationint score;Create the variable name and type
Initializationint score = 0;Give the variable its first value
Assignmentscore = 95;Store a new value later

  • Good habit: initialize local variables when practical, especially when a later expression depends on them.

Variable Basics: Complete Program

The same variable can be read, used in an expression, and assigned a new value.

public class VariableBasics {
    public static void main(String[] args) {
        int userAge = 19;
        int graduationYear = 2028;
        double accountBalance = 125.75;

        System.out.println("Age: " + userAge);
        System.out.println("Graduation year: " + graduationYear);
        System.out.println("Balance: " + accountBalance);

        userAge = userAge + 1;
        accountBalance = accountBalance - 20.00;

        System.out.println("Next birthday age: " + userAge);
        System.out.println("Balance after purchase: " + accountBalance);
    }
}

  • Trace the variables userAge and accountBalance before and after reassignment

  • example: VariableBasics.java

Common Error: Uninitialized Local Variable

Java does not allow a local variable to be read before the compiler can prove the variable has a value.

public class UninitializedVariableBroken {
    public static void main(String[] args) {
        int userAge;
        System.out.println(userAge);
    }
}

  • This is an intentional compiler-error example.

  • Expected result: variable userAge might not have been initialized

  • example: UninitializedVariableBroken.java

Multiple Variables in One Statement?

Java allows several variables of the same type to be declared in one statement.

Allowed, but easy to overlook

int numProtons, numNeutrons, numElectrons;
double width, height;

  • All variables in the same statement have the same type.

  • Without an initializer, each local variable still needs a value before it can be read.

Clearer for beginner code

int numProtons = 0;
int numNeutrons = 0;
int numElectrons = 0;

double width = 0.0;
double height = 0.0;

  • One variable per line makes tracing and debugging easier.

  • This style also makes later changes safer.

Keywords vs Predefined Identifiers

A keyword has a fixed meaning in Java. A predefined identifier comes from the Java libraries.

CategoryExamplesCan you use it as a variable name?

Predefined identifiersSystem, String, Scanner, MathTechnically possible in some contexts, but do not do it

  • Avoid names that conflict with standard Java names. It makes code harder to understand.

Conventions are not always required by the compiler, but they are expected in readable Java code.

Constants with final

A constant is a named value that should not change after initialization.

public class ConstantExample {
    public static void main(String[] args) {
        final double TAX_RATE = 0.12;
        double grossPay = 750.00;
        double taxes = grossPay * TAX_RATE;

        System.out.println("Taxes: " + taxes);
    }
}

  • The keyword final prevents accidental reassignment.

  • Use constants for values with meaning: tax rates, limits, conversion factors, and fixed labels.

Assignment Compatibility

Some assignments are safe automatically. Others require an explicit cast because information may be lost.

AssignmentAllowed?Why

Type Conversion: Complete Program

Casting changes how Java treats a value in an expression. It does not magically fix an expression after integer division already happened.

public class TypeConversionDemo {
    public static void main(String[] args) {
        int pointsEarned = 17;
        int pointsPossible = 20;

        double automaticConversion = pointsEarned;
        double wrongPercent = pointsEarned / pointsPossible * 100.0;
        double correctPercent = (double) pointsEarned / pointsPossible * 100.0;

        System.out.println("Automatic int-to-double: " + automaticConversion);
        System.out.println("Wrong percent: " + wrongPercent);
        System.out.println("Correct percent: " + correctPercent);

        double temperature = 98.9;
        int truncatedTemperature = (int) temperature;
        System.out.println("Truncated temperature: " + truncatedTemperature);
    }
}

  • Watch the difference between pointsEarned / pointsPossible and (double) pointsEarned / pointsPossible

  • example: TypeConversionDemo.java

Integer Overflow

An integer type has a limited range. If an operation goes past the range, the result can wrap around.

public class OverflowExample {
    public static void main(String[] args) {
        int maxValue = Integer.MAX_VALUE;
        System.out.println("maxValue: " + maxValue);
        System.out.println("maxValue + 1: " + (maxValue + 1));
    }
}

  • This program compiles and runs, but the second value is not mathematically correct.

  • Overflow is a logic problem, not a syntax problem.

Floating-Point Rounding Pitfall

Floating-point numbers are stored in binary, so some decimal values cannot be represented exactly.

public class FloatingPointPitfall {
    public static void main(String[] args) {
        double total = 0.1 + 0.2;
        System.out.println(total);
        System.out.printf("%.2f%n", total);
    }
}

  • The first output may show a long approximation.

  • The formatted output hides extra digits, but it does not change how the value is stored.

Precedence and Parentheses

Java follows operator precedence. Parentheses make the programmer's intent obvious.

public class ArithmeticExpressions {
    public static void main(String[] args) {
        int x = 7;
        int y = 4;
        int z = 2;

        int result1 = x + y * z;
        int result2 = (x + y) * z;
        double result3 = x + y / 2.0;

        System.out.println("x + y * z = " + result1);
        System.out.println("(x + y) * z = " + result2);
        System.out.println("x + y / 2.0 = " + result3);
    }
}

  • Multiplication and division happen before addition and subtraction unless parentheses change the order.

  • example: ArithmeticExpressions.java

Integer Division and Modulo

Integer division gives the quotient. Modulo gives the remainder.

public class DivisionModuloDemo {
    public static void main(String[] args) {
        int totalMinutes = 135;
        int hours = totalMinutes / 60;
        int minutes = totalMinutes % 60;

        System.out.println(totalMinutes + " minutes is:");
        System.out.println(hours + " hour(s)");
        System.out.println(minutes + " minute(s)");

        int cents = 287;
        int dollars = cents / 100;
        int leftoverCents = cents % 100;
        System.out.println(cents + " cents = $" + dollars + " and " + leftoverCents + " cents");
    }
}

  • Use / when you need whole groups; use % when you need what is left over.

  • example: DivisionModuloDemo.java

Math Methods and Random Numbers

Java's standard library provides methods for common math operations and pseudorandom values.

import java.util.Random;

public class MathRandomDemo {
    public static void main(String[] args) {
        double radius = 3.0;
        double area = Math.PI * Math.pow(radius, 2.0);
        double diagonal = Math.sqrt(3 * 3 + 4 * 4);

        Random rand = new Random(7);
        int dieRoll = rand.nextInt(6) + 1;
        int randomScore = rand.nextInt(101);

        System.out.println("Circle area: " + area);
        System.out.println("3-4-5 diagonal: " + diagonal);
        System.out.println("Die roll: " + dieRoll);
        System.out.println("Random score: " + randomScore);
    }
}

  • A fixed seed makes the random sequence repeatable, which is helpful for demos and testing.

  • example: MathRandomDemo.java

Characters and Strings: Complete Program

This program combines char, String, indexing, searching, and uppercase conversion.

public class StringsCharactersDemo {
    public static void main(String[] args) {
        char firstInitial = 'A';
        String firstName = "Ava";
        String lastName = "Nguyen";
        String fullName = firstName + " " + lastName;

        System.out.println("Initial: " + firstInitial);
        System.out.println("Full name: " + fullName);
        System.out.println("Length: " + fullName.length());
        System.out.println("First character: " + fullName.charAt(0));
        System.out.println("Last name starts at index: " + fullName.indexOf(lastName));
        System.out.println("Uppercase: " + fullName.toUpperCase());
        System.out.println("Original still unchanged: " + fullName);
    }
}

  • Notice that toUpperCase() returns a new string; the original string is unchanged.

  • example: StringsCharactersDemo.java

Input and Output

Output Streams

System.out is Java's standard output stream. It sends text to the terminal.

MethodBehavior
System.out.print(...)print without moving to a new line
System.out.println(...)print and then move to a new line
System.out.printf(...)print using a format string

  • Exact output matters: spaces, punctuation, decimal digits, and newlines all count.

Input with Scanner

Scanner reads tokens from standard input. A token is usually separated by whitespace.

import java.util.Scanner;

public class ScannerInputDemo {
    public static void main(String[] args) {
        Scanner scnr = new Scanner(System.in);

        String name = scnr.next();
        int age = scnr.nextInt();
        double gpa = scnr.nextDouble();

        System.out.println("Name: " + name);
        System.out.println("Age next year: " + (age + 1));
        System.out.println("GPA: " + gpa);
    }
}

  • Sample input: Morgan 18 3.75

  • example: ScannerInputDemo.java

Formatted Output with printf

Formatted output is important when expected output requires a fixed number of decimal places or aligned columns.

public class FormattedOutputDemo {
    public static void main(String[] args) {
        String item = "Notebook";
        int quantity = 3;
        double price = 2.5;
        double total = quantity * price;

        System.out.println("Unformatted total: " + total);
        System.out.printf("%-12s %5s %8s%n", "Item", "Qty", "Total");
        System.out.printf("%-12s %5d $%7.2f%n", item, quantity, total);
    }
}

  • %.2f prints a floating-point value with two digits after the decimal point.

  • example: FormattedOutputDemo.java

Extended Example

Salary Calculation Problem

Problem: read hourly wage and hours worked. Compute gross pay, taxes, and net pay.

InputComputationOutput
hourly wagegrossPay = hourlyWage * hoursWorkedgross pay
hours workedtaxes = grossPay * TAX_RATEtaxes
fixed tax ratenetPay = grossPay - taxesnet pay

  • This combines variables, input, arithmetic, constants, and formatted output.

Salary Calculation: Complete Program

import java.util.Scanner;

public class SalaryCalculation {
    public static void main(String[] args) {
        Scanner scnr = new Scanner(System.in);

        double hourlyWage = scnr.nextDouble();
        int hoursWorked = scnr.nextInt();
        double grossPay = hourlyWage * hoursWorked;
        double taxRate = 0.12;
        double taxes = grossPay * taxRate;
        double netPay = grossPay - taxes;

        System.out.printf("Gross pay: $%.2f%n", grossPay);
        System.out.printf("Taxes: $%.2f%n", taxes);
        System.out.printf("Net pay: $%.2f%n", netPay);
    }
}

  • Sample input: 18.75 40

  • live coding: SalaryCalculation.java

Debugging Variables and Expressions

Most beginner bugs in this chapter come from values not being what the programmer thought they were.

  • Print intermediate values temporarily

  • Trace variables with a table before running the program

  • Check integer division before assigning to double

  • Check whether the input order matches the Scanner calls

  • Check output formatting last, after the calculation is correct

public class DebugPrintExample {
    public static void main(String[] args) {
        int pointsEarned = 17;
        int pointsPossible = 20;
        double percent = (double) pointsEarned / pointsPossible * 100.0;

        System.out.println("DEBUG percent = " + percent);
        System.out.printf("Final score: %.1f%%%n", percent);
    }
}

Style Guidelines for Chapter 2

  • Use meaningful names: hourlyWage, not x

  • Initialize variables close to where they are declared

  • Use constants for values with meaning: TAX_RATE, MINUTES_PER_HOUR

  • Add spaces around operators: grossPay = wage * hours;

  • Use parentheses when they make an expression easier to read

  • Keep output statements separate enough that exact formatting is easy to inspect

Summary

Key Takeaways

  • A variable is a named memory location with a type and a value

  • Initialization gives a variable its first value; assignment changes a value later

  • Java identifiers are case-sensitive and should follow naming conventions

  • Arithmetic expressions depend on operator precedence and operand types

  • Integer division truncates; modulo gives the remainder

  • Casting must happen before integer division if the goal is a decimal result

  • Strings use zero-based indexing and many methods return new strings

  • Scanner input and formatted output require exact order and exact format
