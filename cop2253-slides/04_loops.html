Loop Concepts

Why Loops?

A loop repeats a group of statements while a condition is true.

  • Without a loop

    • Repeated work often becomes copied code

    • Copied code is hard to update and easy to break.

  • With a loop

    • The repeated action is written once

    • The loop can repeat a fixed number of times.

    • The loop can also repeat until input tells it to stop.

    • Each trip through the loop body is called an iteration.

The Four Questions for Any Loop

Every loop should answer the same four questions.

  • Start: What value does the loop use first?

  • Condition: What must be true for the loop to continue?

  • Body: What work happens during one iteration?

  • Update: What changes so the loop can eventually stop?

If one of these pieces is missing, the loop will probably be wrong.

While Loops: Repeat Until a Condition Changes

while Loop Pattern

A while loop checks the condition before each iteration.

int count = 1;

while (count <= 5) {
    System.out.println("Count: " + count);
    count++;
}

  • If the condition is false at the start, the body runs zero times.

  • A while loop is useful when we do not know the number of iterations ahead of time.

While Loop Example

This program repeats a simple print statement five times.

public class WhileCounter {
    public static void main(String[] args) {
        int count = 1;

        while (count <= 5) {
            System.out.println("Count: " + count);
            count++;
        }

        System.out.println("Done");
    }
}

  • Watch count: it starts at 1, prints, then increases.

  • The loop stops after count becomes 6.

  • example: WhileCounter.java

Sentinel-Controlled Loops

A sentinel value is a special input value that means “stop.”

  • Example input: 10 1 6 3 0

  • If 0 is the sentinel, the program processes 10, 1, 6, and 3.

  • The sentinel itself is not part of the calculation.

  • Sentinel loops are useful when the amount of input is unknown.

Sentinel-Controlled Loop Example: Average

This program averages positive integers and stops when the user enters 0.

import java.util.Scanner;

public class SentinelAverage {
    public static void main(String[] args) {
        Scanner scnr = new Scanner(System.in);
        int currValue = scnr.nextInt();
        int valuesSum = 0;
        int numValues = 0;

        while (currValue > 0) {
            valuesSum = valuesSum + currValue;
            numValues = numValues + 1;
            currValue = scnr.nextInt();
        }

        System.out.println("Average: " + (valuesSum / numValues));
    }
}

  • Sample input: 10 1 6 3 0

  • example: SentinelAverage.java

do-while Loop

A do-while loop checks the condition after the body.

int choice;

do {
    System.out.println("1. Continue");
    System.out.println("0. Quit");
    choice = scnr.nextInt();
} while (choice != 0);

  • The body always runs at least once.

  • This pattern works well for menus and repeated prompts.

Do-While Loop Example: Menu

This example repeats a small menu until the user enters 0.

import java.util.Scanner;

public class MenuLoop {
    public static void main(String[] args) {
        Scanner scnr = new Scanner(System.in);
        int choice;

        do {
            System.out.println("1. Print greeting");
            System.out.println("0. Quit");
            choice = scnr.nextInt();

            if (choice == 1) {
                System.out.println("Hello!");
            }
        } while (choice != 0);

        System.out.println("Goodbye");
    }
}

  • Sample input: 1 1 0

  • example: MenuLoop.java

For Loops: counter-controlled repetition

Increment and Decrement Operators

The operators ++ and -- change a variable by one.

  • count++ means count = count + 1.

  • count-- means count = count - 1.

  • As a separate statement, ++count and count++ both increase the variable.

  • Inside a larger expression, pre-increment and post-increment behave differently.

  • For beginner code, avoid complicated expressions that mix several increments.

for Loop Pattern

A for loop puts the start, condition, and update in one line.

for (int count = 1; count <= 5; count++) {
    System.out.println("Count: " + count);
}

  • int count = 1 creates and initializes the counter.

  • count <= 5 decides whether the next iteration runs.

  • count++ updates the counter after each iteration.

  • Use this pattern when the loop is naturally counter-based.

For Loop Execution Order

Each part of a for loop does not run at the same time.

  • The initialization runs once at the beginning.

  • The condition is checked before each iteration.

  • The loop body runs when the condition is true.

  • The update runs after the body.

  • Then Java goes back to check the condition again.

For Loop Example: Counter

This program prints a count up and then a count down.

public class ForLoopTrace {
    public static void main(String[] args) {
        for (int count = 1; count <= 5; count++) {
            System.out.println("Up: " + count);
        }

        for (int count = 5; count >= 1; count--) {
            System.out.println("Down: " + count);
        }
    }
}

  • The first loop uses count++.

  • The second loop uses count--.

  • example: ForLoopTrace.java

Pre and Post Increment

This example shows the difference when increment is used inside another expression.

public class IncrementOperators {
    public static void main(String[] args) {
        int num = 5;

        System.out.println("Start: " + num);
        System.out.println("Pre-increment: " + ++num);
        System.out.println("After pre-increment: " + num);
        System.out.println("Post-increment: " + num++);
        System.out.println("After post-increment: " + num);
    }
}

  • Pre-increment changes the value before the expression uses it.

  • Post-increment uses the current value first, then changes it.

  • example: IncrementOperators.java

Loops with Strings

Processing a String One Character at a Time

A String is a sequence of characters. A loop can visit each character by index.

String word = "Java";

for (int i = 0; i < word.length(); i++) {
    char ch = word.charAt(i);
    System.out.println(i + ": " + ch);
}

  • String indexes start at 0.

  • The last valid index is word.length() - 1.

  • The loop condition uses i < word.length(), not i <= word.length().

Counting Letters in a String

This program counts alphabetic characters and ignores digits or punctuation.

import java.util.Scanner;

public class CountLetters {
    public static void main(String[] args) {
        Scanner scnr = new Scanner(System.in);
        String inputWord = scnr.next();
        int numLetters = 0;

        for (int i = 0; i < inputWord.length(); i++) {
            char ch = inputWord.charAt(i);
            if (Character.isLetter(ch)) {
                numLetters++;
            }
        }

        System.out.println("Number of letters: " + numLetters);
    }
}

  • Sample input: 123abc...xyz

  • example: CountLetters.java

Build a New String in a Loop

This program keeps only alphabetic characters.

import java.util.Scanner;

public class RemoveNonAlpha {
    public static void main(String[] args) {
        Scanner scnr = new Scanner(System.in);
        String input = scnr.nextLine();
        String result = "";

        for (int i = 0; i < input.length(); i++) {
            char ch = input.charAt(i);
            if (Character.isLetter(ch)) {
                result = result + ch;
            }
        }

        System.out.println(result);
    }
}

  • Sample input: -Hello, 1 world$!

  • example: RemoveNonAlpha.java

Replacing Until Done

Use a while loop when the number of replacements is unknown.

import java.util.Scanner;

public class SingleSpaces {
    public static void main(String[] args) {
        Scanner scnr = new Scanner(System.in);
        String text = scnr.nextLine();

        while (text.indexOf("  ") != -1) {
            text = text.replace("  ", " ");
        }

        System.out.println(text);
    }
}

  • The loop stops when no double-space remains.

  • example: SingleSpaces.java

Domain Name Validation

This example checks a domain name one character at a time.

  • Allowed characters: letters, digits, periods, and hyphens.

  • Any other character makes the domain invalid.

  • The loop keeps checking even after finding one invalid character.

public class DomainNameValidation {
    public static void main(String[] args) {
        String domain = "uwf.edu";
        boolean isValid = true;

        for (int i = 0; i < domain.length(); i++) {
            char ch = domain.charAt(i);
            boolean allowed = Character.isLetterOrDigit(ch)
                    || ch == '.'
                    || ch == '-';
            if (!allowed) {
                isValid = false;
            }
        }

        System.out.println(domain + " valid? " + isValid);
    }
}

  • example: DomainNameValidation.java

Nested Loops

Nested Loop Idea

A nested loop is a loop inside another loop.

  • The outer loop controls the larger repeated task.

  • The inner loop completes its repetitions for each outer-loop iteration.

  • Nested loops are useful for tables, grids, combinations, and repeated patterns.

  • A simple way to think about it: for each row, print each column.

Nested Loop: Multiplication Table

The outer loop chooses the row. The inner loop chooses the column.

public class NestedLoopTable {
    public static void main(String[] args) {
        for (int row = 1; row <= 3; row++) {
            for (int col = 1; col <= 4; col++) {
                System.out.print(row * col + "\t");
            }
            System.out.println();
        }
    }
}

  • The inner loop finishes all columns before the outer loop moves to the next row.

  • example: NestedLoopTable.java

Histogram with an Inner Loop

The outer loop reads values. The inner loop prints one row of asterisks.

import java.util.Scanner;

public class Histogram {
    public static void main(String[] args) {
        Scanner scnr = new Scanner(System.in);
        int numAsterisks = scnr.nextInt();

        while (numAsterisks >= 0) {
            for (int i = 0; i < numAsterisks; i++) {
                System.out.print("*");
            }
            System.out.println();
            numAsterisks = scnr.nextInt();
        }

        System.out.println("Goodbye");
    }
}

  • Sample input: 3 5 2 -1

  • example: Histogram.java

Loop Control and Debugging

break Statement

A break statement exits the nearest loop immediately.

for (int count = 1; count <= 10; count++) {
    if (count == 7) {
        break;
    }
    System.out.print(count + " ");
}
System.out.println();

  • This prints 1 2 3 4 5 6.

  • The loop stops before printing 7.

continue Statement

A continue statement skips the rest of the current iteration.

for (int count = 1; count <= 10; count++) {
    if (count == 5) {
        continue;
    }
    System.out.print(count + " ");
}
System.out.println();

  • This prints every number from 1 to 10 except 5.

  • The loop does not stop. It only skips one iteration.

Break and Continue

This program shows continue and break in the same loop.

public class BreakContinue {
    public static void main(String[] args) {
        for (int count = 1; count <= 10; count++) {
            if (count == 5) {
                continue;
            }
            if (count == 8) {
                break;
            }
            System.out.print(count + " ");
        }
        System.out.println();
    }
}

  • Predict which numbers appear before running the program.

  • example: BreakContinue.java

Infinite Loops

An infinite loop never reaches a false condition.

int count = 1;

while (count <= 5) {
    System.out.println("Count: " + count);
    // missing count++
}

  • This loop keeps printing Count: 1.

  • The condition stays true because count never changes.

  • When a loop does not stop, check the update statement first.

  • example: MissingUpdateLoopWarning.java

Common Loop Errors

Most loop bugs come from the start, condition, or update.

  • Missing update: the loop variable never changes, so the loop may never stop.

  • Wrong boundary: the loop runs one too many or one too few times.

  • Wrong starting value: the first iteration uses the wrong value.

  • Sentinel included: the stop value accidentally becomes part of the sum or average.

  • Assignment in condition: = stores a value; == compares values.

Loop-condition Error Example

This example shows a common loop-condition mistake.

import java.util.Scanner;

public class AssignmentInWhileBroken {
    public static void main(String[] args) {
        Scanner scnr = new Scanner(System.in);
        char userChoice = 'y';

        while (userChoice = 'y') {
            System.out.println("Repeat");
            userChoice = scnr.next().charAt(0);
        }
    }
}

  • The condition must be boolean.

  • Use userChoice == 'y' for comparison.

  • example: AssignmentInWhileBroken.java

Develop Loops Incrementally

Loop programs are easier when built in small steps.

  1. First, read one input value and print it back.

  2. Then, write the loop condition and make sure the loop stops.

  3. Next, add the calculation inside the loop.

  4. Then, add formatting and final output.

  5. Finally, test boundary cases and unusual input.

Do not write a long loop and debug everything at once.

Summary

Key Takeaways

  • A loop repeats while its condition is true.

  • Every loop needs a start, condition, body, and update.

  • Use while for unknown repetition and sentinel-controlled input.

  • Use for for counter-controlled repetition.

  • Use String.length() and charAt() to process text in a loop.

  • Nested loops are useful for tables, grids, combinations, and repeated patterns.

  • break exits a loop; continue skips to the next iteration.

  • Most loop bugs are off-by-one errors, missing updates, or incorrect stop conditions.

Before Next Class

  • Practice predicting loops before running them.

  • For each loop, write down the first value, last value, and stopping condition.

  • Test loops with small input first.

  • When processing input, check whether the sentinel is accidentally included.

  • When processing strings, remember the last valid index is length() - 1.
