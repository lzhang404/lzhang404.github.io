Class Metadata and Member Lookup

Class<?> a = Report.class;
Class<?> b = report.getClass();
Class<?> c = Class.forName(className);

Method m = c.getMethod("run", String.class);

  • getMethods() returns public methods, including inherited methods.

  • getDeclaredMethods() returns methods declared directly in the class.

Create and Invoke at Runtime

Class<?> rawType = Class.forName(className);
Class<? extends ReportTask> type =
    rawType.asSubclass(ReportTask.class);
ReportTask task = type.getDeclaredConstructor()
                      .newInstance();
Method method = type.getMethod(
    "run", String.class);
Object result = method.invoke(task, "weekly");

  • Lookup fails when the class, constructor, or method does not exist.

  • InvocationTargetException wraps an exception thrown by the invoked method.

Runtime Annotations

@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.METHOD)
public @interface Command {
    String value();
}

  • RUNTIME makes the annotation visible to reflection.

  • METHOD limits where the annotation may appear.

  • The runner discovers marked methods, validates them, and invokes accepted methods.

3. Data and Configuration Formats

External Text to Validated Java

try (InputStream in = App.class
        .getResourceAsStream("/app.properties")) {
    Properties p = new Properties();
    p.load(in);
    String text = p.getProperty("server.port");
    int port = Integer.parseInt(text);
}

  • A classpath resource travels with the application.

  • Properties stores keys and values as strings.

  • Convert the text, then validate the application rules.

JSON Structure and Java Representations

{
  "name": "Harbor Store",
  "open": true,
  "items": [
    { "sku": "A17", "price": 12.5 }
  ]
}

  • Use object mapping for a stable shape.

  • Use JsonNode for a flexible shape or selected fields.

YAML Structure

store:
  name: "Harbor Store"
  open: true
  tags:
    - local
    - "open late"

  • Indentation expresses nesting.

  • A dash starts a list item.

  • Quotes protect text that may be interpreted as another type.

Reading an XSD

<xs:element name="book">
  <xs:complexType>
    <xs:sequence>
      <xs:element name="title" type="xs:string"/>
      <xs:element name="pages" type="xs:positiveInteger"/>
    </xs:sequence>
    <xs:attribute name="id" type="xs:string" use="required"/>
  </xs:complexType>
</xs:element>

  • The root element is book.

  • title comes before a positive pages value.

  • The id attribute is required.

Valid XML Instance

<book id="B7">
  <title>Clean Code</title>
  <pages>464</pages>
</book>

  • Well-formed XML follows XML syntax.

  • Schema-valid XML also follows the required structure, types, and attributes.

5. Generics

Generic Types, Methods, and Bounds

Box<String> name = new Box<>();

static <T extends Comparable<T>> T max(T a, T b) {
    return a.compareTo(b) >= 0 ? a : b;
}

  • The compiler checks the selected type and removes many casts.

  • A bound states which operations are safe for T.

Generic Invariance

List<Integer> integers = new ArrayList<>();
// List<Number> numbers = integers;  // compile-time error

  • Integer is a subtype of Number.

  • List<Integer> is not a subtype of List<Number>.

  • Otherwise, code could add a Double to a list of integers.

Wildcard Read and Write Rules

ParameterSafe ReadSafe WriteBest Fit
List<? extends Number>Read as NumberCannot add a specific numberThe method mainly reads values
List<? super Integer>Read only as ObjectMay add an IntegerThe method writes integer values

Reading needs a safe upper type. Writing needs a destination known to accept the value.

Copying Between Related Lists

static <T> void copy(
        List<? super T> destination,
        List<? extends T> source) {
    for (T value : source) {
        destination.add(value);
    }
}

The source supplies T values. The destination accepts T values.

Type Erasure and Runtime Limits

Generic formRuntime result or restriction
Unbounded TErases to Object
T extends NumberErases to Number
new T() and new T[]Not allowed
instanceof List<String>Not allowed
instanceof List<?>Allowed because it checks only the list type
