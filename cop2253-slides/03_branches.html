What You Should Be Able To Do

  • Write a condition that evaluates to true or false

  • Use braces and indentation to make branch structure clear

  • Choose independent if statements only when multiple branches may run

  • Choose if / else-if / else when exactly one branch should run

  • Write range checks like (age >= 16) && (age < 25)

  • Predict output by tracing branch conditions in order

  • Test boundary cases, not just the most obvious input

The main habit: before running code, ask which condition is checked first, which branch executes, and which branches are skipped.

Boolean Expressions

Boolean Data Type

A boolean variable stores one of exactly two values: true or false.

  • Branch conditions must evaluate to boolean

  • Comparison expressions also evaluate to boolean

  • A boolean variable can give a condition a meaningful name

ExpressionPossible resultMeaning
age >= 18true or falseIs the person an adult?
score >= 70true or falseIs the grade passing?
choice != 0true or falseDid the user choose something other than 0?

Boolean Basics

This program stores comparison results in boolean variables, then prints them.

public class BooleanBasics {
    public static void main(String[] args) {
        int age = 19;
        int score = 84;

        boolean isAdult = age >= 18;
        boolean isPassing = score >= 70;
        boolean hasPerfectScore = score == 100;

        System.out.println("Age: " + age);
        System.out.println("Score: " + score);
        System.out.println("Adult? " + isAdult);
        System.out.println("Passing? " + isPassing);
        System.out.println("Perfect score? " + hasPerfectScore);
    }
}

  • Trace each boolean assignment before looking at the output.

  • example: BooleanBasics.java

Assignment vs. Equality

Beginners often confuse = with ==. They do completely different jobs.

public class Equality {
    public static void main(String[] args) {
        int age = 18;            // assignment: store 18 in age
        int requiredAge = 18;

        if (age == requiredAge) { // equality test: compare two values
            System.out.println("Exactly old enough");
        }
        else {
            System.out.println("Not the required age");
        }

        System.out.println("age is still " + age);
    }}

  • = stores a value in a variable.

  • == compares two primitive values.

  • example: Equality.java

Logical Operators

AND, OR, NOT

Logical operators combine or negate boolean expressions.

OperatorNameTrue when...Example
&&ANDAll conditions are true(age >= 18) && hasTicket
||ORAt least one condition is true(age < 18) || (age >= 60)
!NOTThe condition is false!isReady

  • Common error: write &&, not &; write ||, not |, when you want normal logical operators.

Truth Table for AND / OR

ABA && BA || B
falsefalsefalsefalse
falsetruefalsetrue
truefalsefalsetrue
truetruetruetrue

  • AND is stricter: one false value makes the whole expression false.

  • OR is more flexible: one true value makes the whole expression true.

Logical Operators

This example names three different conditions and prints their results.

public class LogicalOperators {
    public static void main(String[] args) {
        int age = 20;
        boolean hasTicket = true;
        boolean hasCoupon = false;

        boolean canEnter = (age >= 18) && hasTicket;
        boolean getsDiscount = (age < 18) || (age >= 60) || hasCoupon;
        boolean needsHelp = !hasTicket;

        System.out.println("Can enter? " + canEnter);
        System.out.println("Gets discount? " + getsDiscount);
        System.out.println("Needs help? " + needsHelp);
    }
}

Range Checks: Java Is Not Algebra

A math-style chained comparison does not work in Java.

GoalDo not writeWrite this instead
Age from 16 through 2416 <= age < 25(age >= 16) && (age < 25)
Score from 70 through 8970 <= score < 90(score >= 70) && (score < 90)
Outside 0 through 100score < 0 > 100(score < 0) || (score > 100)

  • Every comparison must have a left operand and a right operand.

  • Use AND when a value must satisfy two limits at the same time.

Short-Circuit Evaluation

&& and || may stop early once the final result is already known.

public class ShortCircuit {
    public static void main(String[] args) {
        int count = 0;
        int sum = 100;

        if ((count != 0) && (sum / count > 10)) {
            System.out.println("Average is high");
        }
        else {
            System.out.println("No average can be computed safely");
        }

        boolean isTeacher = true;
        boolean hasAccessCode = false;
        if (isTeacher || hasAccessCode) {
            System.out.println("Access granted");
        }
    }
}

  • && stops early when the left side is false.

  • || stops early when the left side is true.

  • example: ShortCircuit.java

Why Short-Circuiting Matters

The first condition can protect the second condition from a runtime error.

ExpressionWhat happens when count == 0?
(count != 0) && (sum / count > 10)Safe. The right side is skipped.
(sum / count > 10) && (count != 0)Unsafe. Division happens before the safety check.

  • Put safety checks first: nonzero denominator, non-null object, valid index, or nonempty string.

Branch Patterns

Simple if

A branch is a program path taken only when a condition is true.

PatternMeaning
if (condition) { ... }Run the body only if the condition is true
condition falseSkip the body and continue after the branch

  • Example situation: print a senior discount message only when age >= 60.

  • Use braces even for one statement. It prevents mistakes when adding a second line later.

if and if/else

This example shows both a simple if and a two-way if/else.

import java.util.Scanner;

public class ConditionalExecution {
    public static void main(String[] args) {
        Scanner scnr = new Scanner(System.in);

        System.out.print("Enter age: ");
        int age = scnr.nextInt();

        if (age >= 60) {
            System.out.println("Eligible for a senior discount");
        }

        System.out.print("Enter an integer: ");
        int number = scnr.nextInt();

        if (number % 2 == 0) {
            System.out.println(number + " is even");
        }
        else {
            System.out.println(number + " is odd");
        }
    }
}

  • Sample input: 65 7

  • live coding: ConditionalExecution.java

Independent if Statements vs. else-if Chain

These two patterns look similar but mean different things.

PatternHow many branches can run?Use when...
Several separate if statementsZero, one, or manyConditions are independent
if / else-if / elseExactly one branch in the chainChoices are mutually exclusive

  • Common mistake: use separate if statements for categories where only one category should be chosen.

Branch Pattern

This program intentionally uses a boundary value to show the difference between independent if statements and an else-if chain.

public class BranchPattern {
    public static void main(String[] args) {
        double salary = 10000.00;

        System.out.println("Independent if statements:");
        if (salary <= 10000.00) {
            System.out.println("Bracket A message printed");
        }
        if (salary >= 10000.00) {
            System.out.println("Bracket B message printed");
        }

        System.out.println();
        System.out.println("if / else-if chain:");
        if (salary <= 10000.00) {
            System.out.println("Bracket A message printed");
        }
        else if (salary >= 10000.00) {
            System.out.println("Bracket B message printed");
        }
    }
}

  • The salary is exactly 10000.00, so the independent checks both become true.

  • example: BranchPattern.java

Nested Branches

A branch body can contain another branch. This is called nesting.

  • Nested code can express requirements like: salary is low, age is high enough, and month is December.

  • Deep nesting is sometimes clear for a first example, but can become hard to read.

  • Often, a nested structure can be rewritten as one condition using &&.

Nested ideaEquivalent combined condition
if salary ok, then if age ok, then if month ok(salary < 10000.00) && (age >= 60) && (month == 12)

Nested Bonus

This program mirrors the nested bonus example from lecture notes.

public class NestedBonus {
    public static void main(String[] args) {
        int month = 12;
        int age = 64;
        double salary = 9500.00;
        double bonus = 0.00;

        if (salary < 10000.00) {
            if (age >= 60) {
                if (month == 12) {
                    bonus = 0.20 * salary;
                    salary = salary + bonus;
                }
            }
        }

        System.out.printf("Bonus: $%.2f%n", bonus);
        System.out.printf("New salary: $%.2f%n", salary);
    }
}

  • Which condition would stop the bonus if changed.

  • live coding: NestedBonus.java

Comparing Values Safely

String Comparisons

Strings are objects. Use methods to compare their text.

ComparisonWhat it checksBeginner rule
name == otherNameWhether two references point to the same objectAvoid for text comparison
name.equals(otherName)Whether the text contents match exactlyUse this for exact text
name.equalsIgnoreCase(otherName)Whether text matches ignoring capitalizationUseful for user input

String Comparison

This program shows why equals() is the safe beginner habit for Strings.

public class StringComparison {
    public static void main(String[] args) {
        String storedPassword = "java123";
        String userInput = new String("java123");

        if (storedPassword == userInput) {
            System.out.println("== says the strings are the same object");
        }
        else {
            System.out.println("== says the references are different");
        }

        if (storedPassword.equals(userInput)) {
            System.out.println("equals() says the text matches");
        }
    }
}

  • Point out that the text matches even though the two object references are different.

  • example: StringComparison.java

Floating-Point Comparisons

Floating-point values are approximate, so equality can surprise you.

  • Computers store many decimal values as approximations.

  • Do not depend on == for most double calculations.

  • Use a small tolerance called an epsilon when checking whether two results are close enough.

IdeaExpression
Exact equalitytotal == expected
Close enoughMath.abs(total - expected) < epsilon

Floating-Point Comparison

This example uses 0.1 + 0.2, a classic floating-point surprise.

public class FloatingPointComparison {
    public static void main(String[] args) {
        double total = 0.1 + 0.2;
        double expected = 0.3;
        double epsilon = 0.000001;

        System.out.println("total: " + total);
        System.out.println("expected: " + expected);
        System.out.println("Using == : " + (total == expected));
        System.out.println("Using epsilon: " + (Math.abs(total - expected) < epsilon));
    }
}

  • The epsilon approach checks whether two values are close enough for the program's purpose.

  • example: FloatingPointComparison.java

Switch Statements

When switch Is Useful

A switch statement is useful when one expression is compared against several exact constant values.

Good fit for switchUsually better with if/else
menu option 1, 2, 3, 4ranges such as score >= 90
letter grade 'A', 'B', 'C'compound conditions using && or ||
day name, command word, enum valuefloating-point comparisons

  • Remember break unless you intentionally want fall-through behavior.

Switch

This example maps a letter grade to a message.

public class Switch {
    public static void main(String[] args) {
        char letterGrade = 'B';
        String message;

        switch (letterGrade) {
            case 'A':
                message = "Excellent";
                break;
            case 'B':
                message = "Good work";
                break;
            case 'C':
                message = "Satisfactory";
                break;
            default:
                message = "Meet with the instructor";
                break;
        }

        System.out.println(message);
    }
}

  • Change letterGrade to 'A', 'C', or 'F' and predict the message.

  • example: Switch.java

A conditional expression chooses between two values.

FormMeaning
condition ? valueIfTrue : valueIfFalseEvaluate the condition, then choose one of two values
(score >= 70) ? "Pass" : "Fail"Choose a short label based on the score

  • Use it for short value selection, not for complicated multi-line decisions.

  • For beginners, if/else is usually clearer when there are several statements.

Debugging Branches Incrementally

When a branch program does not work, debug the decision process before rewriting the whole program.

  1. Print the input values that the program actually read.

  2. Print the boolean condition result before the branch.

  3. Test a boundary table: below, at, and above each cutoff.

  4. Check whether the branch structure should be independent if statements or one else-if chain.

  5. Remove temporary debugging output after the logic is correct.

Exam-Style Tracing Question

Summary

Key Takeaways

  • Every branch condition must evaluate to true or false.

  • = assigns; == compares primitive values.

  • Use && for conditions that must all be true; use || when at least one condition is enough.

  • Write ranges as two complete comparisons, such as (age >= 16) && (age < 25).

  • Use independent if statements only when multiple branches may run.

  • Use an if / else-if / else chain when exactly one category should be chosen.

  • Use .equals() for String text comparison and epsilon for most floating-point equality checks.

  • Debug branch programs with trace tables and boundary tests.
