Array Concept

What an Array Is

A normal variable stores one data item. An array stores a list of data items of the same type.

Common problems arrays help solve:

  • A basketball program may need points for four quarters.

  • A gradebook may need many quiz scores.

  • A roster may need many names.

  • Declaring one variable for each item does not scale.

What an array gives us:

  • One name for the whole group.

  • One index for each item in the group.

Array Vocabulary: Definitions and Examples

Use these words carefully. They appear in code, compiler messages, and exam questions.

  • array: one variable name that refers to a sequence of elements.

  • element: one value stored inside the array.

  • index: the position number used to access one element.

  • length: the number of elements allocated in the array.

  • last valid index: one less than the length.

int[] pointsPerQuarter = new int[4];
pointsPerQuarter[0] = 22;
pointsPerQuarter[3] = 28;

Array Declaration and Allocation

An array variable is a reference. The new operator creates the actual array object.

int[] gameScores = new int[4];
String[] names = new String[3];
double[] temperatures = new double[7];

  • The brackets [] mean this variable refers to an array

  • The value inside new int[4] is the number of elements

  • Default values are assigned when the array is created

  • For int and double, the default value is zero

  • For boolean, the default value is false

Array Basics

This program creates an array, stores values, and prints selected elements.

public class ArrayBasics {
    public static void main(String[] args) {
        int[] pointsPerQuarter = new int[4];

        pointsPerQuarter[0] = 22;
        pointsPerQuarter[1] = 19;
        pointsPerQuarter[2] = 12;
        pointsPerQuarter[3] = 28;

        System.out.println("Q1 points: " + pointsPerQuarter[0]);
        System.out.println("Q4 points: " + pointsPerQuarter[3]);
        System.out.println("Number of quarters: " + pointsPerQuarter.length);
    }
}

Array Index Boundaries

For an array with length 4, the valid indexes are 0, 1, 2, and 3.

  • The first element is at index 0

  • The last element is at index array.length - 1

  • Index array.length is already one step too far

  • An out-of-range array access usually causes an ArrayIndexOutOfBoundsException at runtime

public class ArrayOutOfBoundsBroken {
    public static void main(String[] args) {
        int[] userWeights = new int[3];
        userWeights[0] = 122;
        userWeights[1] = 119;
        userWeights[2] = 117;

        System.out.println(userWeights[3]);
    }
}

  • This program compiles, but it fails when it runs because the index is invalid

  • example: ArrayOutOfBoundsBroken.java

Array Initialization

When the values are already known, an initializer is shorter and clearer.

int[] highTemps = {93, 80, 62, 75, 74, 89, 97};
char[] vowels = {'a', 'e', 'i', 'o', 'u'};
String[] days = {"Mon", "Tue", "Wed", "Thu", "Fri"};

  • The array length is determined by the number of values

  • This style creates a perfect size array

  • You cannot later add one more element to the same array object

  • To change the size, create a new array or use ArrayList

Iterating Through Arrays

The Standard Array Loop

Most array work uses a loop that starts at index 0 and stops before array.length.

for (int i = 0; i < myArray.length; ++i) {
    // use myArray[i]
}

  • Start with i = 0 because the first index is 0

  • Use i < myArray.length, not i <= myArray.length

  • Use myArray[i] inside the loop body

  • This pattern works even when the array size changes

Array Example: Read and Print Values

This program reads eight values into an array, then prints the values back out.

import java.util.Scanner;

public class ArrayPrinter {
    public static void main(String[] args) {
        Scanner scnr = new Scanner(System.in);
        final int NUM_ELEMENTS = 8;
        int[] userVals = new int[NUM_ELEMENTS];

        System.out.println("Enter " + NUM_ELEMENTS + " integer values...");
        for (int i = 0; i < userVals.length; ++i) {
            System.out.print("Value: ");
            userVals[i] = scnr.nextInt();
        }

        System.out.print("You entered: ");
        for (int i = 0; i < userVals.length; ++i) {
            System.out.print(userVals[i] + " ");
        }
        System.out.println();
    }
}

  • example: ArrayPrinter.java

Array Example: Sum, Average, and Max

Many array problems follow the same structure: initialize an answer, visit every element, and update the answer.

public class ArraySumMax {
    public static void main(String[] args) {
        int[] scores = {83, 92, 76, 95, 88};
        int sum = 0;
        int max = scores[0];

        for (int i = 0; i < scores.length; ++i) {
            sum += scores[i];
            if (scores[i] > max) {
                max = scores[i];
            }
        }

        double average = (double) sum / scores.length;
        System.out.println("Sum: " + sum);
        System.out.println("Average: " + average);
        System.out.println("Max: " + max);
    }
}

  • example: ArraySumMax.java

Enhanced for Loop for Reading Values

An enhanced for loop visits each element directly.

public class EnhancedFor {
    public static void main(String[] args) {
        String[] teamRoster = {"Mike", "Scottie", "Toni"};

        System.out.println("Current roster:");
        for (String playerName : teamRoster) {
            System.out.println(playerName);
        }
    }
}

  • The loop variable receives one element value at a time

  • It is clean when you only need to read or print elements

  • It does not give you the index number

  • Use a regular indexed loop when you need to update elements by position

  • example: EnhancedFor.java

Modifying and Copying Arrays

Array Example: Modify Elements

When you need to change elements, use an indexed loop.

public class ModifyArray {
    public static void main(String[] args) {
        int[] userVals = {5, 67, -5, -4, 5, 6, 6, 4};

        for (int i = 0; i < userVals.length; ++i) {
            if (userVals[i] < 0) {
                userVals[i] = 0;
            }
        }

        System.out.print("New numbers: ");
        for (int i = 0; i < userVals.length; ++i) {
            System.out.print(userVals[i] + " ");
        }
        System.out.println();
    }
}

  • example: ModifyArray.java

Array References and True Copies

Assigning one array reference to another does not copy all elements.

int[] oldVals = {10, 20, 30};
int[] aliasVals = oldVals; // same array object
int[] copyVals = new int[oldVals.length];

for (int i = 0; i < oldVals.length; ++i) {
    copyVals[i] = oldVals[i];
}

  • aliasVals and oldVals refer to the same array

  • Changing aliasVals[0] also changes oldVals[0]

  • To make a separate copy, create a new array and copy each element

Array Example: Reverse Values

Reversing an array means swapping pairs from the outside toward the middle.

public class ReverseArray {
    public static void main(String[] args) {
        int[] values = {10, 20, 30, 40, 50, 60, 70, 80};

        for (int i = 0; i < values.length / 2; ++i) {
            int oppositeIndex = values.length - 1 - i;
            int temp = values[i];
            values[i] = values[oppositeIndex];
            values[oppositeIndex] = temp;
        }

        System.out.print("Reversed: ");
        for (int i = 0; i < values.length; ++i) {
            System.out.print(values[i] + " ");
        }
        System.out.println();
    }
}

  • Index 0 swaps with the last index

  • Index 1 swaps with the second-to-last index

  • A temporary variable prevents one value from being overwritten

  • The loop stops halfway through the array

  • example: ReverseArray.java

Common Array Loop Errors

  • Using i <= array.length instead of i < array.length

  • Starting at index 1 and accidentally skipping the first element

  • Using a fixed number like 8 instead of array.length

  • Initializing max to 0 when the array might contain only negative values

  • Changing a loop variable but forgetting to use that variable as the index

  • Copying values in one direction during a reverse operation without saving a temporary value

Arrays and Methods

Primitive Parameters vs Array Parameters

Primitive values and array references behave differently when passed to methods.

  • A primitive argument passes a copy of the value

  • Changing the primitive parameter does not change the original variable

  • An array argument passes a copy of the reference

  • The method can use that reference to change the original array elements

  • Reassigning the parameter itself does not change the caller's array variable

Method Example: Array Parameter

This method receives an array reference and fills every element.

public class ArrayParameter {
    public static void fill(int[] arrayRef, int value) {
        for (int i = 0; i < arrayRef.length; ++i) {
            arrayRef[i] = value;
        }
    }

    public static void reassign(int[] arrayRef) {
        arrayRef = new int[2];       // only changes the local parameter
        arrayRef[0] = 99;            // does not change cookiesBaked
    }

    public static void main(String[] args) {
        int[] cookiesBaked = new int[3];
        fill(cookiesBaked, 10);
        reassign(cookiesBaked);

        for (int i = 0; i < cookiesBaked.length; ++i) {
            System.out.println("Day " + i + ": " + cookiesBaked[i]);
        }
    }
}

  • arrayRef[i] = value; changes the original array elements.

  • arrayRef = new int[2]; only reassigns the local parameter.

  • Reassigning the parameter does not change the caller's array variable.

  • example: ArrayParameter.java

Method Example: Return an Array

A method can create a new array and return the array reference.

public class ReturnArray {
    public static int[] initializeArray(int value, int size) {
        int[] result = new int[size];
        for (int i = 0; i < result.length; ++i) {
            result[i] = value;
        }
        return result;
    }

    public static void main(String[] args) {
        int[] dataArray = initializeArray(5, 7);

        for (int i = 0; i < dataArray.length; ++i) {
            System.out.print(dataArray[i] + " ");
        }
        System.out.println();
    }
}

  • example: ReturnArray.java

Array Sizes

Perfect Size Arrays

A perfect size array is completely full. The number of used elements equals the array length.

int[] highTemps = {93, 80, 62, 75, 74, 89, 97};
System.out.println(highTemps.length);

  • Use this when the number of items is fixed by the problem

  • Seven days in a week is a good example

  • Five vowels is a good example

  • The array length and the number of used elements are the same

Oversize Arrays

An oversize array has extra capacity. A separate size variable tracks how many elements are actually used.

public class OversizeList {
    public static void main(String[] args) {
        String[] shoppingList = new String[5];
        int shoppingListSize = 0;

        shoppingList[shoppingListSize] = "Milk";
        ++shoppingListSize;
        shoppingList[shoppingListSize] = "Oranges";
        ++shoppingListSize;
        shoppingList[shoppingListSize] = "Apples";
        ++shoppingListSize;

        System.out.println("Items used: " + shoppingListSize);
        for (int i = 0; i < shoppingListSize; ++i) {
            System.out.println(shoppingList[i]);
        }
    }
}

  • shoppingList.length is the capacity

  • shoppingListSize is the number of used elements

  • Loops should usually stop at shoppingListSize, not shoppingList.length

  • Oversize arrays are useful when the final number of items is not known in advance

  • example: OversizeList.java

Perfect Size vs Oversize

  • Use a perfect size array when the number of values is fixed and known

  • Use an oversize array when the list may grow up to a maximum capacity

  • A perfect size array has no unused slots

  • An oversize array may contain unused default values after the used portion

  • Always name the size variable clearly, such as numItems, scoresSize, or shoppingListSize

Two-Dimensional Arrays

Two-Dimensional Array Concept

A two-dimensional array is often used like a table with rows and columns.

int[][] table = new int[2][3];
table[0][0] = 55;
table[1][2] = 99;

  • The first index chooses the row

  • The second index chooses the column

  • table.length is the number of rows

  • table[0].length is the number of columns in row 0

  • A 2 by 3 integer array has 6 integer elements

2D Array Example: Quiz Score Table

This program stores quiz scores in a small table.

public class TwoDimensionalArray {
    public static void main(String[] args) {
        int[][] quizScores = {
            {90, 85, 88},       // row 0: student 0 scores
            {76, 92, 81}        // row 1: student 1 scores
        };

        System.out.println("Student 0, quiz 1: " + quizScores[0][1]);
        System.out.println("Rows: " + quizScores.length);
        System.out.println("Columns in row 0: " + quizScores[0].length);

        for (int row = 0; row < quizScores.length; ++row) {          // visit each row
            for (int col = 0; col < quizScores[row].length; ++col) { // visit columns in that row
                System.out.print(quizScores[row][col] + " ");
            }
            System.out.println();
        }
    }
}

ArrayList

What an ArrayList Adds

An ArrayList is a resizable list from Java's standard library.

  • Use an array when the size is fixed or when the assignment asks for arrays

  • Use ArrayList when the list needs to grow or shrink more naturally

  • An ArrayList stores reference types, such as String or Integer

  • Use ArrayList<Integer>, not ArrayList<int>

  • Import it with import java.util.ArrayList;

Common ArrayList Methods

The syntax is different from arrays, but the indexing idea is similar.

  • add(element) appends an element to the end

  • get(index) returns the element at an index

  • set(index, element) replaces an element

  • size() returns the number of elements currently in the list

  • Array indexes use []; ArrayList access uses methods

ArrayList<Integer> valsList = new ArrayList<Integer>();
valsList.add(31);
int firstVal = valsList.get(0);
valsList.set(0, 119);
int usedSize = valsList.size();

ArrayList Example: Add, Get, Set, and Size

This program creates an ArrayList, changes one element, and prints the list.

import java.util.ArrayList;

public class ArrayListBasics {
    public static void main(String[] args) {
        ArrayList<Integer> valsList = new ArrayList<Integer>();

        valsList.add(31);       // add appends a value and increases size
        valsList.add(41);
        valsList.add(59);

        System.out.println("First value: " + valsList.get(0));
        valsList.set(1, 119);   // set replaces an existing value

        System.out.println("List size: " + valsList.size());
        for (int i = 0; i < valsList.size(); ++i) {  // ArrayList uses size(), not length
            System.out.println(valsList.get(i));     // get reads a value by index
        }
    }
}

  • example: ArrayListBasics.java

ArrayList Example: Incorrect Element Type

This example uses the wrong type argument because ArrayList cannot use a primitive type name.

import java.util.ArrayList;

public class ArrayListPrimitiveBroken {
    public static void main(String[] args) {
        ArrayList<int> scores = new ArrayList<int>();
        scores.add(90);
        System.out.println(scores.get(0));
    }
}

  • Use ArrayList<Integer> instead of ArrayList<int>

  • Use ArrayList<Double> instead of ArrayList<double>

  • Use ArrayList<Character> instead of ArrayList<char>

Summary

Key Takeaways

  • Arrays store many elements under one name

  • Array indexes start at 0 and end at array.length - 1

  • The standard array loop is for (int i = 0; i < array.length; ++i)

  • Use indexed loops when you need the index or need to change elements

  • Use enhanced for loops when you only need to read each element

  • Array parameters let methods modify the original array elements

  • Perfect size arrays are full; oversize arrays need a separate used-size variable

  • Use ArrayList when a list needs to grow more naturally
