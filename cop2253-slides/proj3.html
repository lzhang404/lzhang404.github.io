Project: Mini Pet Shelter

Overview

In this project, you will write a small Java program for a pet shelter.

The project practices:

  • objects and classes
  • constructors
  • inheritance
  • abstract classes
  • interfaces
  • method overriding
  • polymorphism
  • ArrayList
  • file input
  • file output

Project background

A small animal shelter keeps records for dogs and cats.

Every pet has a name. Dogs and cats are both pets, but they behave differently. A dog says Woof! and needs dog care. A cat says Meow! and needs cat care.

In this project, every pet should be careable. This means the abstract Pet class will implement the Careable interface. Then each subclass, such as Dog and Cat, will provide its own care instructions.

Your program will read the name of an input file from the console. Then it will open that file, create the correct pet objects, store all pets in one list, print each pet's information, care instruction, and sound, and save a short summary report to a file.

Required files

Submit these Java files:

Pet.java
PetShelterManager.java

The instructor will provide one or more input files for testing.

Your program will create this output file when it runs:

shelter_report.txt

Program input

The program should read one input file name from the console.

The input file name will be one token with no spaces.

Example console input:

pets1.txt

Your program should open the file with that name.

Do not hard-code the input file name.

Do not print a prompt.

Pet input file format

Each line in the input file describes one pet.

The file uses this format:

type name

Example input file:

DOG Buddy
CAT Luna
DOG Max
CAT Milo

You may assume the input file is correctly formatted.

Files and required code

Pet.java

This file contains the abstract parent class, the interface, and the two pet subclasses.

This file must contain:

public abstract class Pet implements Careable
interface Careable
class Dog extends Pet
class Cat extends Pet

Only Pet should be public.

Do not write public before Careable, Dog, or Cat.

Interface: Careable

Create an interface named Careable in Pet.java.

The interface must require one method:

String getCareInstructions()

The abstract class Pet must implement Careable. Since Dog and Cat extend Pet, they are also careable pets.

Abstract class: Pet

Create an abstract class named Pet.

Pet must implement the Careable interface:

public abstract class Pet implements Careable

Required instance variable:

private String name;

Required constructor:

public Pet(String name)

Required methods:

public String getName()
public abstract String makeSound()
public abstract String getType()
public abstract String getCareInstructions()
public String toString()
  • getName() returns the pet's name.
  • makeSound() returns the sound made by the pet.
  • getType() returns the pet type.
  • getCareInstructions() returns the care instructions for the pet.
  • toString() returns the pet information as a String.

Required toString() format:

Dog: Buddy
Cat: Luna

Use the @Override annotation before toString().

Class: Dog

Create a class named Dog in Pet.java.

Dog must extend Pet.

Required constructor:

public Dog(String name)

Required methods:

public String makeSound()
public String getType()
public String getCareInstructions()
  • makeSound() returns Woof!
  • getType() returns Dog
  • getCareInstructions() returns the dog's name followed by needs walks and dog food.

Use the @Override annotation before each required method in Dog.

Required dog care format:

Buddy needs walks and dog food.

Class: Cat

Create a class named Cat in Pet.java.

Cat must extend Pet.

Required constructor:

public Cat(String name)

Required methods:

public String makeSound()
public String getType()
public String getCareInstructions()
  • makeSound() returns Meow!
  • getType() returns Cat
  • getCareInstructions() returns the cat's name followed by needs cat food and a clean litter box.

Use the @Override annotation before each required method in Cat.

Required cat care format:

Luna needs cat food and a clean litter box.

PetShelterManager.java

This file contains the main program.

This file must contain:

public class PetShelterManager

The PetShelterManager class must contain this method:

public static void main(String[] args) throws IOException

For this project, file reading, object creation, counting, console output, and file output should be handled inside main().

Use the File I/O approach covered in class:

  • Use Scanner to read the input file name from the console.
  • Use FileInputStream to open the input file.
  • Use Scanner to read from the file stream.
  • Use hasNextLine() to read all lines from the file.
  • Create one ArrayList<Pet> to store all dog and cat objects.
  • Update the dog count and cat count while reading the file.
  • Use a loop to print each pet's information, care instruction, and sound.
  • Use FileOutputStream to open the output file.
  • Use PrintWriter to write the summary report.
  • Close file resources when finished.

Main method requirements

Your main() method should follow this order:

read the input file name from the console
create one ArrayList<Pet>
create dog and cat counters

open the selected input file
read each pet from the file
create the correct Dog or Cat object
add each pet object to the list
update the dog or cat counter
close the input file resources

print each pet's information, care instruction, and sound

create shelter_report.txt
write the summary report
close the output file resources

Do not print a prompt before reading the input file name.

When printing pet information, use a Pet reference from the list. Because Pet implements Careable, your code should be able to call getCareInstructions() directly from the Pet reference.

For example, the printing logic should be based on this idea:

Pet pet = pets.get(i);

System.out.println(pet);
System.out.println(pet.getCareInstructions());
System.out.println(pet.makeSound());

Do not cast a Pet object to Careable in PetShelterManager.

Restrictions

  • Do not create a Pet object directly. Pet must be abstract.
  • Pet must implement the Careable interface.
  • Dog and Cat must extend Pet.
  • Do not cast Pet to Careable in PetShelterManager.
  • Do not store dogs and cats in separate lists. Use one ArrayList<Pet>.
  • Do not hard-code the input file name.
  • Do not hard-code the pets, sample output, dog count, or cat count.
  • Do not decide pet sounds in PetShelterManager. Each subclass should define its own sound.
  • Do not decide care instructions in PetShelterManager. Each subclass should define its own care instructions.
  • Do not write console output into shelter_report.txt.
  • Do not skip file input or file output.
  • Your program must work with different valid input files provided by the instructor.
